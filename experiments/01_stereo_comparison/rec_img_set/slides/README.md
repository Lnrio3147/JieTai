# IGEV++ RT 与 LiteAnyStereo 对比汇报材料

本目录是从统一测试结果中整理出的 PPT 素材包，适合制作约 10 页的算法可行性汇报。详细推理输出未重复复制，避免交付目录膨胀；所有主图、单场诊断图、点云预览、统计数据和报告均已收拢。

## 一句话结论

LiteAnyStereo 在统一 73 场定量测试中总体精度更高、严重失效更少，RTX 4090 FP32 核心推理约快 3.18 倍，建议作为二期优先候选；但 IGEV++ RT 在更多普通单场和部分刻度/窄边缘场景仍有优势，应保留为强基线。

## 建议 PPT 结构

### 第 1 页：测试目的

标题建议：`IGEV++ RT 与 LiteAnyStereo 双目算法可行性对比`

- 目标：统一数据、统一 ROI、统一参考和统一点云规则，比较两套算法；
- 范围：模型推理、视差图、定量评价和点云生成；
- 不包含：RK3588/RKNN 部署、真实毫米级测量认证。

### 第 2 页：数据与统一标准

- `rec_img_set` 共测试 203 组唯一双目图；
- FDJYP-3 的 73 组具有 Foundation Stereo 评价参考；
- 固定 ROI：`disp[234:1052, 126:638]`，大小 `818×512`；
- 两模型使用完全相同的 PNG 输入、FP32 和同机 RTX 4090；
- 203 组均生成两份视差和 PLY，共 406 个点云文件。

可选图片：`01_主图/09_跨数据组可行性案例.jpg`。

### 第 3 页：总体精度

插图：`01_主图/01_全73场精度指标.png`

| 模型 | EPE↓ | D1↓ | Bad1↓ | Bad2↓ | Bad3↓ |
| :--- | ---: | ---: | ---: | ---: | ---: |
| IGEV++ RT | 4.6739 | 10.6413% | 40.6562% | 19.7851% | 12.6567% |
| LiteAnyStereo | **2.0762** | **7.4666%** | **40.1102%** | **17.4400%** | **9.8854%** |

结论：LAS 的平均 EPE 降低 `55.58%`，五项宏平均指标全部更低。

### 第 4 页：稳定性与场景分布

插图：`01_主图/02_逐场EPE分布.png`

- 最大单场 EPE：IGEV `108.79 px`，LAS `12.32 px`；
- EPE > 10 px 的场景：IGEV 5 场，LAS 1 场；
- 单场 EPE 获胜数：IGEV 44 场，LAS 29 场；
- 结论：LAS 的主要优势是抑制异常失效，并非每一场都领先。

### 第 5 页：速度与资源

插图：`01_主图/03_核心推理速度.png`

| 项目 | IGEV++ RT | LiteAnyStereo |
| :--- | ---: | ---: |
| 平均核心推理 | 115.09 ms | **36.16 ms** |
| FPS | 8.69 | **27.65** |
| CUDA 峰值 allocated | 711 MiB | **659 MiB** |
| 参数量 | **4.17 M** | 7.60 M |
| checkpoint | **16.17 MiB** | 29.35 MiB |

结论：LAS 当前 GPU 前向约快 `3.18×`；该速度不能直接外推到 RK3588。

### 第 6 页：空洞与点云覆盖

插图：`01_主图/04_空洞对比.jpg`

- `656565-0004`：LAS 点云有效率 98.87%，IGEV 为 95.74%；
- `camera-...-0162`：反例，IGEV 为 93.86%，LAS 为 91.44%；
- 无参考场景只能评价覆盖完整性，不能把“填满”直接当作正确深度。

### 第 7 页：边缘表现

插图：`01_主图/05_边缘对比.jpg`

- `0018`：LAS 把边缘 EPE 从 88.71 px 降到 30.06 px，显著缓解 IGEV 灾难性失配；
- `0038`：IGEV 边缘 EPE 4.74 px，优于 LAS 的 11.33 px；
- 结论：LAS 尾部更稳定，IGEV 在部分窄边缘仍更好。

### 第 8 页：曝光鲁棒性

插图：`01_主图/06_曝光对比.jpg`

- 严重欠曝 `0028`：69.75% 像素低于灰度 25，模型间 MAE 达 50.15 px；
- 金属高亮 `0035`：模型间 MAE 仅 0.95 px；
- 结论：严重曝光截断是独立于模型的数据风险，平滑结果不等于正确结果。

### 第 9 页：刻度与细节

插图：`01_主图/07_刻度细节对比.jpg`

- 部分刻度图中 IGEV 保留更多高频响应，LAS 视差更平滑；
- 这证实了“IGEV 看起来更清楚”的观察；
- 但如果刻度只是平面印刷纹理，IGEV 的响应也可能是纹理复制伪影；
- 需要“平面印刷标尺 + 已知深度蚀刻标尺”才能判断真实几何优劣。

### 第 10 页：结论与建议

- LiteAnyStereo：总体误差更低、严重失效更少、当前 GPU 推理更快，建议作为二期优先候选；
- IGEV++ RT：更多普通单场 EPE 略优，部分边缘/刻度细节更强，保留为回归基线；
- 203 场、406 份点云证明工程链路可运行，但不等于测量系统合格；
- 下一步优先级：修复螺纹/一般场景极线几何 → 建立标定 manifest → 标准件真实几何评价 → RK3588/RKNN 部署。

## 重要口径

1. Foundation Stereo 是统一工程评价参考，不是人工或激光真值；
2. “模型间差异”在无参考场景中不能称为误差；
3. 点云文件成功生成只证明流程可运行，不证明毫米级精度；
4. RTX 4090 FP32 延迟不能直接代表 RK3588 NPU 延迟；
5. 不应说 LiteAnyStereo 全面优于 IGEV，应表述为“总体及尾部稳定性更优，但存在明确反例”。
