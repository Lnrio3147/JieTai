# 实验 7：RGB + LiteAnyStereo 视差双流融合

实验7把实验6中“推理后规则融合”改成“训练阶段特征融合”：LiteAnyStereo保持冻结，现有视差离线读取；左RGB和视差分别编码，在四个尺度门控融合，再联合预测主体外轮廓和边界。

## 框架

```text
左 RGB ─→ ImageNet ResNet18 ─┐
                             ├→ 1/4、1/8、1/16、1/32 门控融合
视差/梯度/有效性 → ResNet18 ─┘                 │
                                               ↓
                                         U-Net 解码器
                                         ├─ 主体概率
                                         └─ 边界概率
                                               │
                                   阈值0.075 + 实验4孔洞约束
                                               │
                              实验7.1 连续实体几何约束
                                               │
                       实验7.2 前景溢出检测 + 高置信连通体救援（当前推荐）
```

- 输入分辨率：`576×1024`；
- RGB编码器与视差编码器均使用本机ResNet18预训练权重初始化；
- 视差输入为逐场景鲁棒归一化视差、Sobel视差梯度、有效性三通道；
- 损失：`0.35 BCE + 0.55 Tversky(β=0.7) + 0.10 Boundary BCE`；
- 训练：88张，batch size 2，混合精度，第29轮早停；
- 最佳checkpoint：第19轮，按验证集宏类别IoU选择；
- 默认阈值：只在验证集选择，在整体Precision不低于0.94的候选中最大化宏类别F2。

## 与实验 6 V4.1 对比

以下仍是已经参与工程比较的21张开发比较图，不是全新的最终测试集。

| 方法 | IoU | Precision | Recall | Boundary F1 | 宏类别 IoU |
|---|---:|---:|---:|---:|---:|
| 实验6 V4.1 | 0.88294 | 0.89025 | 0.99079 | 0.34108 | 0.85455 |
| 实验7 RGB-D，阈值0.075 | 0.88682 | 0.89102 | 0.99470 | 0.39183 | 0.85445 |
| 实验7 RGB-D + 实验4 | 0.88852 | 0.88997 | **0.99818** | 0.43998 | 0.86367 |
| 实验7.1 连续实体约束 | 0.89153 | 0.89316 | **0.99797** | 0.48117 | 0.86663 |
| **实验7.2 前景溢出救援** | **0.94555** | **0.94890** | 0.99628 | **0.55904** | **0.91375** |

实验7.1在实验4结果上进行高斯轮廓平滑、窄裂缝闭合、最大外轮廓填充和单主体约束；≤256像素的小孔作为散点清理，实验4保留的更大视差孔洞重新叠回，避免误填真实通孔。

实验7.1相对V4.1：主体漏检像素从 `20146` 降到 `4448`，Recall提高约 `0.72` 个百分点，Precision提高约 `0.29` 个百分点，Boundary F1提高约 `0.140`。测试Mask平均外轮廓周长由实验7的 `1721.8` 降至 `1606.5`，更接近人工Mask的 `1416.8`，同时所有输出都保持单一前景连通域。

实验7.2针对另一种更严重的错误：低阈值结果把主体与大面积背景连成一块，此时“保留最大连通域”会稳定地选错。新规则不使用GT，先检测前景面积随置信度上升的异常收缩，再寻找高置信区间内的连通体突变点；仅在“低置信前景明显溢出、候选包围框几乎占满画面、高置信连通体突然收紧”同时成立时，切换到高置信主体并进行闭合和外轮廓填充。验证集21张均未触发，比较集只触发 `luowen_656565_0031` 和 `luowen_656565_0033`，其余19张完整沿用实验7.1。

| 难例 | 实验7.1 IoU / P / R | 实验7.2 IoU / P / R |
|---|---:|---:|
| luowen 0031 | 0.2122 / 0.2122 / 1.0000 | **0.9460 / 0.9877 / 0.9573** |
| luowen 0033 | 0.4257 / 0.4257 / 0.9999 | **0.8794 / 0.9315 / 0.9402** |

实验7.2之后，测试Mask平均外轮廓周长进一步从 `1606.5` 降到 `1511.2`，更接近人工Mask的 `1416.8`；所有21张仍保持单一连通体且没有散乱像素。需要注意，溢出判据是在用户指出0031/0033后形成的，所以这些图已是开发比较图，不能再充当无偏最终测试集。

若更强调去背景，阈值0.15的RGB-D + 实验4可达到 IoU `0.90173`、Precision `0.91041`、Recall `0.98954`、Boundary F1 `0.47669`。

## 当前限制

- 130张图、尤其Jop1/scale/general样本量仍太少；
- 标签只包含外轮廓，无法训练真实孔洞头；
- 连续实体约束只能清理局部碎片，不能凭几何规则补回大面积漏分；
- Jop1整体IoU仍会因低阈值吸收背景而下降；
- 实验7.2解决的是“高置信概率中仍存在正确主体、但低阈值把背景连进来”的情况；如果模型从概率层面就完全认错，它不会强行猜测主体；
- 最终结论仍需要另采并冻结从未参与调参的新测试集。
