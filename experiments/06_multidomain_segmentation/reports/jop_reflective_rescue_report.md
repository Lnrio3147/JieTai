# Jop1 高反光难例修复报告

`jop1_camera_202412091816_0108` 的中央过曝带、黑色刻字和孔洞导致语义概率断裂。它在 tune01 的 0.50 原始预览中 Recall 只有 0.7484。单纯降低阈值虽可把 Recall 提到约 0.956，却会把左侧黑背景同时纳入，不满足“干净主体”的要求。

该图的低阈值真前景视差中位数约为 76.9 px，误收背景约为 56.2 px，存在明确空间分离。因此新增自适应救援：默认保留 V4 实验 4；仅当 Jop1 的基础主体占比和视差可靠性都达到 0.70 时，以实验 5 为种子，在前景侧视差区域内吸收低置信语义像素。

问题图最终 IoU/Precision/Recall 从 V4 的 `0.7208/0.8305/0.8451` 提高到 `0.8035/0.8502/0.9359`。开发比较集总体 IoU 从 0.8810 提高到 0.8829，Recall 从 0.9879 提高到 0.9908；Precision 仅下降 0.0004，Boundary F1 下降 0.0043。

结果入口为 `results/bisenetv2_recall_v4_1_jop_rescue/`。Jop1 训练仍只有 5 张且外观跨度过大，本方法只能作为安全救援分支，根本改善仍需增加银色高反光标尺的独立训练图片。
