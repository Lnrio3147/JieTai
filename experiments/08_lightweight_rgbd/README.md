# Experiment 8: Lightweight RGB-D foreground segmentation

This experiment distils the Experiment 7.2 RGB-D teacher into a deployable
student. The RGB encoder is `mobilenetv4_conv_small`; disparity, Sobel magnitude,
and validity are encoded by three shallow convolutional layers. Geometry controls
four depthwise-separable spatial gates at 1/4, 1/8, 1/16 and 1/32 resolution. An
EMCAD-style decoder produces foreground and boundary logits.

## Data and evaluation protocol

The implementation uses the project's fixed split under
`datasets/training/workpiece-seg-isat-v2`: 88 training images, 21 validation
images, and 21 test images. Validation is used for early stopping and threshold
selection only. The final engineering comparison is reported on the fixed
21-image test split. These 21 images were already used by Experiments 6/7 for
development comparisons, so they are not a new unbiased final test set. Existing
Experiment 7.2/7.1 masks are copied exactly for validation and test; training
targets are generated by the frozen Experiment 7 checkpoint.

The source images are portrait images, so the requested 576 x 1024 resolution is
treated as width x height. Tensor shapes are `[B, C, 1024, 576]`.

## Losses

Base training uses BCE + Tversky + boundary distance-transform supervision.
Distillation uses the requested hard-target formula:

`0.5 * (Dice_GT + BCE_GT) + 0.3 * BCE_TeacherA + 0.2 * BCE_TeacherB`

plus an explicit boundary-head distance-transform term, as required. Teacher A
is eroded with a 3 x 3 kernel for one iteration when loaded; Teacher B preserves
the continuous-entity constraint.

## Complete canonical dataset audit

The 2026-08-24 full audit covers all 353 unique industrial stereo scenes under
`JieTai/datasets` after removing annotation/training/raw/archive duplicates. It
includes 11 groups, with human foreground masks for 317 scenes. Experiment 8
Base obtains the highest all-labelled macro IoU (`0.8846`) and the highest IoU
on the fully unseen FDJYP-0/2 subset (`0.8306`). However, all three current
models show severe background overflow on parts of DE0548, JXP and other_test,
so no model is yet reliable on every dataset directory. Complete contact sheets,
all three masks and the evaluation table are linked from
[`results/all_datasets_353_20260824/REPORT.md`](results/all_datasets_353_20260824/REPORT.md).

## RK3588 export

`export_rknn.py` exports fixed-shape ONNX and supports RKNN-Toolkit2's two-step
hybrid quantization. RGB operations remain INT8, while ONNX nodes belonging to
the geometry encoder and geometry-refinement gates are marked FP16 in the
generated quantization configuration. RKNN conversion requires a Rockchip wheel
whose version matches the target runtime; it is intentionally not installed by
the generic Python requirements file.
